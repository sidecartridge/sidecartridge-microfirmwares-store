# Platform icons

Self-hosted SVG icons used for each platform's `image` in `platforms.json` /
`test/platforms.json` and rendered on the platform cards and catalog header
(EPIC-07, `D-12`).

## Provenance

Each icon is an **original SVG drawn for this store** — a compact, recognizable
mark for the platform (brand-colored rounded tile + logo motif/lettering),
rather than a copied asset. They reference the platforms' well-known logos/marks;
the **trademark/IP risk of resembling those marks was explicitly accepted** by the
project owner (see `D-12`).

| File | Platform | Motif |
| ---- | -------- | ----- |
| `atari-st.svg` | Atari ST | Atari "Fuji" + "ST", red tile |
| `atari-2600.svg` | Atari 2600 | Fuji + "2600", wood-brown tile |
| `atari-8bit.svg` | Atari 8-bit | Fuji + "8-BIT", green tile |
| `nes.svg` | NES | "NES" wordmark + red bar, dark tile |
| `sega-megadrive.svg` | SEGA Megadrive | italic "SEGA" + "MD", blue tile |
| `colecovision.svg` | ColecoVision | "CV / COLECO", red tile |

Marks (Atari, Nintendo/NES, SEGA, Coleco/ColecoVision) are trademarks of their
respective owners. These icons are self-contained (own background), so they read
on both the light and dark themes.
